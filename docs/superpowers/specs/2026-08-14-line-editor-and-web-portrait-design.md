# LINE 編輯指令＋網頁肖像查圖

日期：2026-08-14

## 目標

1. LINE 預設記者；使用者有給「編輯」指令才走編輯消化／生圖。安全框與記者同一套官方置框。
2. 網頁版生圖接上 LINE 已有的真人肖像查圖（維基參考照／多人一律不畫臉），失敗也落檔。

## 不做

上傳參考圖、Rich Menu、強制先選角色才生圖、改安全框幾何、網頁安全框預設改 ON。

## LINE

- 預設 `role=記者`，密度維持 `LINE_DIGEST_DENSITY`（預設 simplified）。
- 偵測到編輯指令 → `role=編輯`，密度改 `standard`（兩行標題、蓋章）。
- 指令形式（不匹配新聞內文出現的「編輯部」）：
  - 整則只有「編輯」／「編輯模式」／「記者」：記住角色、用免費 reply 確認、不生圖。
  - 開頭 `編輯:`／`編輯：`／`編輯`＋換行或空白再接稿。
  - 獨立一行 `指示: 編輯` 或 `指令: 編輯`。
- 之後沒再下指令時沿用上次角色；沒選過就維持記者。
- 指令標記從送進消化的正文剝掉。

## 網頁

- `/api/generate` 已回 `portrait_subjects`。前端生圖時一併送給 `/api/images/generate`。
- 後端 `resolve_portrait`：0 人不管；1 人查維基附圖；2 人以上不畫臉。
- 肖像規則只在後端注入，不把 `PORTRAIT_*` 同步進 `app.js`。
- `generate_news_image` 內部呼叫不重複落檔；網頁直打生圖端才記 `source=web-image`。
