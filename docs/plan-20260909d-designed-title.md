# 第七批：設計標題「更奔放」（2026-09-09）

## 使用者要什麼

> 十點不一樣 設計標題 可以更奔放 參考我們現行的AI設計版標題

附兩張現行 YouTube 封面截圖（badge 是 YouTube 自己的「即將直播」／「50:00」，
所以那是實際上架的成品，不是我們的樣張）。

## 根因：條文寫成「許可」，推不動模型

對照第五批的成品 `20260909-215559-ten-designed.png`：模型只把填色換成金屬金，
版面仍是**兩行等大、齊左、規規矩矩的堆疊**。

上一版的 designed 條文整段是許可句——「you may…」「no longer binds」——
而它前面的整段 TYPOGRAPHY 都是命令句。**許可不會讓模型離開阻力最小的路**：
照舊排版、只換材質，形式上兩邊都沒違反。

所以這一批不是加更多形容詞，是**改語氣**：先用命令句把那個 house style
逐項描述出來（必做），解除綁定的句子退到後面。

## 基準圖和成品差在哪（這五點寫成條文）

| # | 基準圖 | 第五批成品 | 條文 |
|---|---|---|---|
| 1 | 短鉤子（「日本暴雨！」）比解釋句大 1.5–2 倍，解釋句錯開內縮 | 兩行等大齊左 | `SIZE HIERARCHY IS REQUIRED` |
| 2 | 行內關鍵詞換色／進紅框（名古屋、東京／「街道成河」／"致命漏洞"） | 整行一個顏色 | `PULL A KEY WORD OUT INSIDE A LINE`，並明寫「每一行不得是單一平色」 |
| 3 | 飽和平塗黃／白／紅＋粗黑描邊＋硬投影＋微前傾 | 整排同一種金屬金 | 明文否定 `not one uniform polished metallic fill` |
| 4 | 掛 1–2 個小圖示（⚡🔥☔⚠） | 無 | 開放，但限定**無字**符號 |
| 5 | 錯落、不齊平堆疊 | 齊平堆疊 | 「一行一列」改成不再綁**形狀** |

第 3 點特別要點名否定：不寫「不要金屬」，模型手上就只有上一張成品可抄。

## 兩道反向護欄

- **同一個名詞被拆成兩行時不准放大其中一行。** 樣張的「古羅馬圖／拉真浴場」
  就是一個名詞被拆行，照「鉤子放大」辦會把語意拆散。條文寫成
  `ONE EXCEPTION TO THE SIZE HIERARCHY`。
- **版面解放的是形狀，不是行數。** 併行／砍行是為了排版好看動內容，最危險的副作用。

## 這批**沒有**開放的

基準圖右上那些**國旗小標（帶「日本」「印尼」）、地圖上的地名、重複的問號徽章**
都是清單外文字：撞硬規則 (e)（封面錯字＝對外事故），而且國旗那個位置正好是
`compose.paste_cover_ai_note` 要貼 AI示意圖 的角落。要開是另一件事，另外裁。
條文順手把它們逐項列進禁令，免得「圖示可以」被讀成「小標也可以」。

## 驗證

`tests/test_designed_title_house_style.py` 七題，全套 **1203 題綠**。

**但這是 prompt 改動，靜態測試只能釘住條文寫了什麼，證明不了成品會變奔放。**
要證明只有一條路：拿基準圖那組標題（日本暴雨！／降水帶狂轟名古屋、東京 …）
實際生一張，跟使用者的截圖並排看。約 100 秒＋一次 API 費用，**等使用者下令再跑**。
