## 結論

1. **R4 兩項修正無效且出現反效果**：同 digest 對照下，GEMINI 括號入圖 0/2 → 2/2，GPT 側邊留邊反而變薄、底部一張更低。
2. **括號入圖是 GEMINI 的隨機行為，規則措辭影響有限**：舊規則下 R2 中招、本輪基準 0/2；新規則（語義三分）在 % 分支 R3 0/4、本輪 2/2。四輪合看，「標記語義三分」在 R3 的乾淨結果很可能是運氣，不是因果。n=2 的批次，單次差異完全被模型隨機性淹沒。
3. **main 純文字版對 GPT 其實已經夠好**（本輪基準 2/2 全合格，含「when in doubt, make the margin bigger」語句），病灶集中在 GEMINI（壓帶＋側邊薄＋隨機括號）。
4. 與像素版、% 版三線合看，結論一致收斂：**prompt-only 對空間精度與渲染紀律都到不了廣播級一致性，混合版型（APP 控版面與文字）是唯一正解**。純文字版維持現狀即可，不值得再打地鼠。
