# 百分比安全框實驗紀錄（2026-07-23，feat/percent-safe-area，進行中）

## 實驗設定

像素版全滅後（見 `2026-07-23-像素安全框-分析.md`），改測 % 版：
上／左右 approximately 8–10%、底部 18–22%，含「數字與 % 字元嚴禁畫進圖」防護，
數值集中於 `SAFE_MARGIN_PCT`。素材：美軍 B-1 空襲伊朗革命衛隊（自動選型：地圖／位置）。

## 迭代歷程（打地鼠模式）

| 輪 | 修正 | 結果 | 新問題 |
|---|---|---|---|
| 0（使用者手測 6 張） | 初版 % 規則 | 數字入圖 0/6 ✅ | GPT 過度縮小（1張內容只佔畫面一半）；Gemini 3/3 資料來源行壓底部帶 |
| 0.5 | 移除「bigger never smaller」、加上下限夾住（`c0384b4`） | 縮小解決 | GPT 盪到另一極端：側邊距僅 4–6% 貼邊 |
| 1（自動測 5 張） | 下限優先於填滿（`9c0bb06`） | 貼邊大致解決、縮小未復發 | 5/5 總結橫幅壓進底部保留帶（84–91%） |
| 2（自動測 4 張） | 底部帶明確禁入：內容須在上 3/4 內結束（`f62d7dd`） | 橫幅上移 3–5%，GEMINI-2 幾乎合規 | 4/4 仍碰帶；**GEMINI 冒出括號入圖**（`< >` `[ ]` 與佔位詞「內文小標」被渲染） |

## 三輪累計結論

1. **穩定戰果**：「嚴禁畫出數字／%字元」防護句有效——數字入圖 0/14（對照：% 舊版與像素版都大量中招）。approximately＋範圍寫法可能也有貢獻。
2. **prompt 調參天花板現形**：每修一項冒一項（過縮→貼邊→壓帶→括號入圖）。模型對空間規則「有感知、無精度」，收斂不到廣播級一致性。
3. **% 版仍優於其他路線**：純文字版（留邊不一致）＜ % 版 ＜ 理論上的混合版型。像素版全滅墊底。
4. 佐證混合版型（`docs/hybrid-rendering-proposal.md`）為正解：版面與文字由 APP 控制，這整類問題直接消失。

## 狀態

分支調參**尚未收手**，使用者續測中。目前最佳配方＝% 範圍＋approximately＋禁畫數字＋下限優先＋底部帶禁入。
代表性失敗圖：同名 `-R1-`／`-R2-` 開頭 png。
