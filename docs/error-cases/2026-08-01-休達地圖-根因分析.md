# 休達（Ceuta）地圖錯誤：根因分析與修正

**回報日期**：2026-07-31（LINE Bot 實際使用，非測試）
**回報內容**：「地圖又有錯誤案例(GPT) 休達根本不是長這樣」
**證據**：`2026-07-31-休達地圖-GPT-法國錯置＋形狀錯誤-回報原圖.jpg`

## 症狀

一張關於摩洛哥移民湧入西班牙飛地休達的新聞圖，有兩處錯：

1. **「法國啟動快速干預邊境部隊」的 callout 被貼到休達身上**。休達是西班牙在北非
   的飛地，與法國無關；法國內政部長宣布的是強化**法國與西班牙**邊界的管制，是另一
   件事。圖上兩者混在一起，等於宣稱法國在休達部署部隊。
2. **休達的實際形狀不對**（使用者判定）。

## 查修過程的第一個發現：沒有 log 可查

使用者要求「從後台回撈 PROMPT 看看哪一步驟有錯」，但後端**只在失敗路徑 print**，
而且連原始新聞文字都沒帶上；成功的請求完全不留痕跡。這次只能請使用者把原文重貼
一次才查得下去——原文若已遺失，這個案例就查不了。

已修：新增 `request_log.py`，成功的請求也落檔（含輸入、消化結果、最終 prompt），
並以 `request_id` 串起 LINE 成圖檔名，回查入口為 `scripts/find_generation.py`。

## 根因（拿原文重跑消化端定位）

### 1. 地圖類消化 token 預算不足，且截斷後的髒資料會被直接收下

`MAP_ACCURACY_RULES` 要求雙層地圖、多組座標、指北針與比例尺，光 structure 一欄就
吃掉一般預算。實測地圖類用 1500 tokens 幾乎每次第一輪都 `finish_reason=length`
被截斷。程式重試後，第二次生成在長度壓力下會吐出**摻雜垃圾字元的 variable**——
但舊版只檢查 `json.loads` 是否成功，語法合法的垃圾就直接進了生圖 prompt。

實際撞到的污染樣態：

```
[內文小標]休達人口約8萬3000 面積19平方公里】} արվել? +#+#+#+#+assistant to=system  天天中彩票怎样 әскәртәыҟны
[內文小標]法西邊界管制加強】}```  ... Need correct. We accidentally weird. Need final only JSON exact keys.
```

修法：`MAP_DIGEST_MAX_TOKENS = 6000`（地圖／自動判斷專用），並新增
`digest_quality_problem()` 把截斷、外文字元污染、模型英文自言自語一律當失敗重試。

### 2. 放寬預算後浮現的第二種失控

不截斷之後，模型改成把原文每個詞都拆成一條 `[內文小標]` 灌到 **91 行**（含
`[內文小label]` 這種壞掉的標記）。全部是正常中文，字元檢查抓不到。

修法：行數上限 40 行（對逐字模式的完稿腳本留足空間）＋重複行比例偵測。

### 3. 標題讓「回應國」變成主詞（這就是法國錯置的直接來源）

消化端下的標題是：

```
[標題]移民湧入休達 法國強化邊境管制
```

法國與休達並列在標題上，生圖端因此把法國的 callout 畫到休達上。這不是生圖端亂畫，
是消化端給的指示本身就有歧義。

修法：`MAP_ACCURACY_RULES` 新增第 11 條——只有事件發生地能當標題主詞，純粹回應／
抗議／表態的國家一律降到內文小標或 callout，且回應國名要寫進自己的 callout 文字裡。

### 4. 消化模型本身會間歇性脫軌（付費複驗時才浮現）

修完前三項後付費複驗，消化端**連續 3 次**都在 variable 吐出多語言文字碎片（韓文、
西里爾、古吉拉特、馬拉雅拉姆、緬甸文與 ♀ 符號），品質檢查全部擋下、回 502。

量測後確認與模型選擇高度相關（單次呼叫不重試，simplified + 自動判斷）：

| 新聞 | `openai/gpt-5.6-terra` | `anthropic/claude-sonnet-5` |
|------|------------------------|------------------------------|
| 休達 | 2/4 | 4/4 |
| 紅海 | 1/3 | 2/3 |
| 北韓 | 1/3 | 3/3 |
| 合計 | **4/10** | **9/10** |

修法：`.env` 的 `DIGEST_MODEL` 換回 `anthropic/claude-sonnet-5`（也就是程式碼原本的
預設值），重試次數 3 → 5。

## 複驗圖仍存在的問題（歸屬 TODO 項目 11，本輪刻意未處理）

1. **「伊倫昂代」是原文沒有的地名**。Irún／Hendaye 確實是真實的法西邊境關口，但
   原文完全沒提，屬模型自行補入的識別性細節。
2. **休達 → 伊倫昂代之間的黃色虛線**看起來像在描述一條移民路線，原文沒有這條路線。
   消化端的 structure 明確寫了「不是路線」，生圖端仍然畫了。

這兩點落在使用者指示「本輪不動、之後獨立拉出來檢驗」的**項目 11（內容忠實度規則
收緊）**範圍內，故僅記錄為證據，未在本輪修改規則。
