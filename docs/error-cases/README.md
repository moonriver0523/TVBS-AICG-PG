# 錯誤案例庫

生圖結果與預期不符的案例集中存放處，供日後修 prompt／驗證改進效果用。

## 安全框驗收基準

判定生圖是否「邊距無視／貼邊／壓帶」等安全框類錯誤時，一律以 [`docs/examples/tvbs-safe-frame-locked-tool.md`](../examples/tvbs-safe-frame-locked-tool.md) 第四節的官方數值為準（上10.09%／左7.29%／右7.60%／下20.37%），不要另外自訂比例。

## 命名規則

```
YYYY-MM-DD-主題-錯誤類型.jpg          ← 錯誤的生成結果圖
YYYY-MM-DD-主題-錯誤類型-分析.md      ← 對應的原因分析（有才放）
```

同一案例的圖與分析檔名前綴一致，方便配對。

## 安全框系列的最終結論（2026-07-30）

五輪實驗後結案：**安全框不再交給生成模型**。模型有版面的語意概念、沒有度量能力，
寫數字會被畫進圖、寫白話文不收斂、餵引導圖只影響排列、API 遮罩是軟遮罩會整張重繪。
改為「叫模型畫滿（它做得很好）＋後端 `safe_frame.py` 數學置框」，底部安全區從歷史 0 次合格變成 100% 合格。

要重新評估任何「讓模型自己留安全框」的提案前，先讀
[第五輪分析](2026-07-30-參考圖引導與遮罩-分析.md)的「這輪不要再重複的事」。
