# 錯誤案例庫

生圖結果與預期不符的案例集中存放處，供日後修 prompt／驗證改進效果用。

## 命名規則

```
YYYY-MM-DD-主題-錯誤類型.jpg          ← 錯誤的生成結果圖
YYYY-MM-DD-主題-錯誤類型-分析.md      ← 對應的原因分析（有才放）
```

同一案例的圖與分析檔名前綴一致，方便配對。
