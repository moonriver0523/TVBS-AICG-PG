# 交辦：提升生圖解析度能不能救「字多／字超多」的小字與錯字（2026-09-15）

**執行**：「測試」session ／ **驗收**：AICG 監督 session
**來源**：2026-09-15 使用者提出——「字多／字超多 字可能太小失真或錯字的問題，我想到解決方法：提升生圖的解析度，試試看生 2 張測試」
**授權**：使用者明示「生 2 張測試」。**上限 2 張正式對照 ＋ 1 張探路**（見下方），超過要先回報。

## 一、監督已經查到的事（不用重查，但要驗證第 3 點）

### 1. 現在的畫布真的很小

`main.py:3273` 的 `NATIVE_GPT_IMAGE_SIZES` 是唯一的尺寸來源，兩條傳輸層（原生 OpenAI、OpenRouter）共用：

```
"16:9":  "1280x720"     ← 編輯版（安全框 ON）走這個
"21:9":  "1680x720"     ← 記者版官方框走這個
```

**字超多在 1280×720 上要塞 8 個內文塊、123 字**（D16 實拍數據）。
使用者說的「字太小」有明確的物理基礎，**這個假說值得測**。

### 2. ⚠ 前台那個 1K／2K 開關對現在的模型完全沒用

`main.py:3186`：

```python
# 只有支援 resolution enum 的模型才帶 resolution（Gemini / Seedream / Riverflow）；
# GPT 系列不吃 resolution，帶了會 400。
if any(tag in model for tag in ("gemini", "seedream", "riverflow")):
    payload["resolution"] = req.image_size
```

現行模型是 `gpt-image-2.5-sunburst`（`NATIVE_GPT_IMAGE_MODEL`），
走的是 `_openrouter_gpt_size()` 那條**固定 size 表**。
`app.js:1737` 的註解也早就寫了：「GPT 固定 1280×720（忽略解析度切換）；Gemini 才依 1K／2K 變動」。

**所以：不要用前台的 2K 鈕來做這個測試，那是空包彈。**
要測就得動 `NATIVE_GPT_IMAGE_SIZES` 這張表。

### 3. ❓還沒證實：模型到底吃不吃更大的 size

`1680x720`、`1280x720` 都不是 OpenAI 公開文件裡的標準尺寸，卻是會動的，
代表這支模型接受任意尺寸——**但這是推論，沒有實證**。

而且 `main.py:2949` 已經標明 `size` 這個參數**不在 OpenRouter 公開的參數清單裡，屬未公開行為**。
**所以第一件事是探路，不是直接跑對照組。**

## 二、要做的事

### 步驟 0｜探路（1 張，先確認方向可行）

1. 在本機把 `NATIVE_GPT_IMAGE_SIZES["16:9"]` 暫時改成 `"2560x1440"`（正好 2 倍）。
   **改在工作區就好，先不要 commit。**
2. 隨便拿一篇短稿生 1 張，然後**用 `magick identify` 量實際回傳的像素**。
3. 三種結果，分別怎麼走：
   - **真的回 2560×1440** → 往下做步驟 1。
   - **靜靜掉回 1280×720 或 1536×1024** → **測試到此為止**，直接回報。
     那代表模型忽略了 size，這條路走不通，不要再燒錢；
     順便記下它實際落在哪個尺寸（那本身就是有價值的情報）。
   - **400／報錯** → 記下錯誤全文，改試 `1920x1080` 再探一次（這次仍算在探路，不另計）。

⚠**探路這張只看尺寸，不看內容**，不要花時間評字。

### 步驟 1｜正式對照（2 張，這就是使用者授權的那 2 張）

**唯一變因只能是畫布尺寸。** 其餘全部釘死：

### 步驟 2｜判讀（這一段最容易做錯，請照做）

1. **一律用原尺寸看，不准看縮圖。** 裁切放大到 100%（甚至 200%）再判。
   縮圖會吃掉部件，「勳」會看成「動」——這個坑本專案踩過。
2. 每一張逐塊記錄：
   - **錯字數**：字形錯、缺筆畫、簡體字、非中文的亂碼筆畫，各自分開計數。
   - **最小字的實際像素高度**（量一個代表性內文字的字身高度）。
   - **可讀性主觀分**（1–5），並寫一句為什麼。
3. **B 張要換算回同一個顯示尺寸再比**——B 張本來就比較大，字當然比較多像素。
   真正要回答的是：**縮到跟 A 一樣大時，B 的字有沒有比較不會錯、比較好認。**
   所以請額外把 B 張縮到 1280×720 存一份，**用那一份跟 A 比錯字**。
   （原尺寸那份只用來量字高與看筆畫細節。）
