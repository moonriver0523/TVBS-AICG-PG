# YT 24H LIVE 版型（`live24`）落地計畫

2026-09-13。角標定版之後開工，repo 在此之前完全沒動過。

## 使用者裁決（依時間序）

1. 角標**不用向量程式畫，改生圖**；**生成一次做成固定素材**，之後每張封面壓同一張，
   只有日期是程式壓的（日期會變）。
2. Logo 放**右上**（依實際播出，不依概念圖）。
3. 角標款式走 **S 版**（鉻金屬 24H ＋ 立體紅 LIVE ＋ 紅色訊號圓標）。
4. S1（字標懸空＋分離日期板）與 S2（合併藍底）二選一 →**選 S1**。
5. 日期板「全藍色很死板」，要有變化，**授權生圖**，出 10 版 →**選 U2 深藍玻璃反光**。
6. U2 的**鉻金屬邊框再粗一點** → 出 V1／V2 兩檔粗細 →**V2 定版**。

## 定版素材

| 檔 | 來源 | 尺寸 |
|---|---|---|
| `static/brand/live24-badge.png` | `24H LIVE候選/角標素材v9/badge_V2_鉻框再粗.png` | 2675×1225 |
| `static/brand/tvbs-logo-news-white.png` | 09-11 從範本摳出的 TVBS＋NEWS 兩層版 | 314×172 |

⚠️ **兩個檔都是逐位元複製，不可以重新去背或重裁。** 日期壓字區的比例是相對
**這一份** 2675×1225 的裁切量出來的，重新去背 bbox 會變、日期就會掉到鉚邊上。
因此測試裡釘死像素尺寸——有人重新輸出 PNG 時會當場失敗，而不是悄悄跑位。

日期壓字區（相對素材，已內縮避開鉚金屬框）：`(0.097, 0.602, 0.911, 0.924)`。
日期格式 **`YYYY.MM.DD`（點）**，不要沿用 hourly 的 `%Y/%m/%d`。斜度 shear 0.20 對齊角標。

## 這次的範圍與刻意不做的事

**`live24` 是純合成版（composite-only）**：標題、角標、日期、Logo 一律程式壓，
創意階梯只作用在**底圖生成**。理由：標題規格（單行、指定紅、淺描邊、3.5° 斜度）
精確到模型打不中，而這條線本來就有「零錯字」的合成版可用。
不先蓋一條 AI 標題路徑——沒人要求，蓋了就是投機。

底圖三態：
1. **滿版**——一張圖鋪滿。
2. **雙切漸層**——沿用現成 `blend_backgrounds_lr`（接縫 0.40，右格佔 67%）。
3. **雙切疊圖**——大底圖＋右側小照片，白框＋輕微逆時針傾斜＋投影。
   **這次不做，另開一個 commit**：它是唯一要新寫的合成器，而且白框寬度／傾角／
   投影參數還沒從範本量出來。

附圖位對應（省一次來回，先定下來，不對再改）：
- 漸層：左格→左圖、右格→右圖（同 hourly）。
- 疊圖：左格→大底圖、右格→右側小圖。

## 雙切疊圖合成器（2026-09-13）

`compose.compose_live24_inset_background(base, inset)`：大底圖鋪滿＋右側白框斜照片，
回傳的是**底圖**（再送進 `compose_yt_live24_cover` 才有角標與標題）。

| 項目 | 值 | 怎麼量的 |

| 白框 | 6px（0.0056 佔高） | 上緣往下數白色連續像素 |
| 寬 | 0.446（上緣長 856px） | 同上 |
| 高 | **16:9（由左邊緣反推）** | 見下 |

⚠️ **高度不是直接量到的。** 範本上照片的下緣被標題壓住。改量左邊緣：它從 (741,287)
一路到 (805,707) 都還在（0.655 佔高處才被標題蓋掉）。上緣長 856px，取 16:9 時高 481px、
