# 第八批：標題創意拉桿 0–4（2026-09-09）

## 使用者要什麼

> AI 消化的創意奔放程度，能不能設為好幾個等級，讓使用者自己選擇。
> 前台 UI 的呈現方式，做成像你們調整 ai effort 的拉 bar，
> 最左邊是創意最低，最右邊是創意最高。

（附 Claude Code 的 Effort 拉桿截圖：標籤＋當前檔位名稱＋兩端 Faster／Smarter。）

**判讀**：這裡的「創意奔放程度」當成**設計**奔放度——就是他們前一則在看的設計標題。
十點這條線本來就不消化標題字句（使用者直接給兩個標題），所以沒有「改字程度」可調。

## 級距怎麼訂

四級是**由上往下減**：4 就是使用者上一則給的那組現行封面（house style），
往下逐級收回自由。**4 以上不再往上加**——傾斜、疊字、破格會撞死 FIXED 的 (c)(d)(g)，
而且使用者沒要。

| 級 | 名稱 | 這一級長什麼樣 |
|---|---|---|
| 0 | 規矩 | 完全不追加條文＝現行白／黃／紅逐行配色、等大、齊左下 |
| 1 | 微設計 | 字體、描邊、投影、材質、裝飾框放開；**配色、大小、版位一律不動** |
| 2 | 有設計 | 再加：每則行內抓一個關鍵詞換色／壓框、大小落差約 1.2 倍 |
| 3 | 強設計 | 整組 house style：落差 1.5–2 倍、關鍵詞壓紅框、飽和平塗＋粗黑描邊硬投影；**版位仍固定** |
| 4 | 最奔放 | 再加：版位自由、可掛 1–2 個無字小圖示 |

**每一級都用命令句寫，不寫「你可以…」。** 第七批才剛證明許可句推不動模型——
中間級若寫成許可，成品會跟 0 或 4 長一樣，那條拉桿就是騙人的。

**FIXED (a)–(g) 每一級原樣附上**：一字不改、正體中文、程式後貼的三塊區域、不得跨格。
拉桿調的是設計自由度，**永遠不調內容與版面規約**。

3 級特別要明寫 `THE PLACEMENT STILL BINDS`：這一段整體宣告 OVERRIDE，
只是「不提位置」不夠，不點名就會被順手當成解除。

## 介面與 API

- 前台：`<input type="range" min=0 max=4>`＋兩端「規矩／奔放」＋當前檔位名稱，
  照使用者給的 Effort 拉桿長相。舊的紫色 ON/OFF 按鈕移除——留著會有兩個真相源。
- 顯示條件不變：只有十點版型＋「標題由 AI 生成」勾著才出現（合成版的字是程式壓的）。
- API：`title_creativity: int 0–4`。舊的 `title_style: plain | designed` 留作別名
  （plain→0、designed→4），兩個都帶時以 `title_creativity` 為準。
  舊呼叫端與追加修改的回填靠這條。

## 驗證

`tests/test_cover_title_creativity.py` 13 題＋前台 6 題改寫，全套 **1217 題綠**。
釘住的是：0 不追加、每級都帶完整 FIXED、每級都有 OVERRIDE 與自己的級數宣告、
相鄰級條文不得相同、自由度單調遞增、超界 422、舊兩檔仍對應兩端。

**沒驗到（重要）**：靜態測試只能證明**條文**分五級，證明不了**成品**看起來分五級。
生圖模型本身有雜訊，相鄰兩級很可能看起來一樣——尤其 1 與 2。
要驗只能同一組標題各級各生一張並排看。

**也沒開瀏覽器實測拉桿**，只有 markup 測試。
